DI 자료 탐색·개발 보드

설계를 종이에서 교실로 옮기는 첫걸음 · 수업설계카드로 협의하기

사용 방법

1. 카드 옮기기

  • 노트북·크롬북(마우스): 카드를 끌어서 칸에 놓아요.
  • 휴대폰·태블릿·터치: 카드를 한 번 누르고, 놓을 칸의 여기에 놓기를 눌러요.
  • 다시 빼려면 카드를 누르고 더미의 더미로 되돌리기를 눌러요.
  • 빈 카드나 + 새 카드에는 이름을 직접 써요.

2. 진행 순서 (10분)

  1. ① 설계안 확인 · 2분: 내용·역량·기능·평가카드로 Ds에서 정한 수업을 다시 꺼내 놓아요.
  2. ② 필요 자료 나열 · 4분: 활동에 필요한 자원카드를 모두 꺼내요. 확보 가능성은 따지지 않아요.
  3. ③ 역할 분담 · 4분: 자원을 ‘찾아서 그대로 쓸 것 / 함께 만들 것 / 각자 만들 것’ 칸에 나누고 담당·마감을 적어요.

카드는 자원의 종류예요. 메모 칸에 구체적인 자료명을 꼭 적어 주세요. 예: 인터넷자료 → 대기질 공공데이터 / 김○○ / 10.26.

3. 결과 올리기

  • 이미지로 저장을 눌러 PNG를 받고, 패들렛 게시물에 올려요.
  • 글 복사를 눌러 같은 게시물 본문에 붙여 넣어요.
  • 최종 기록은 팀장님 워크시트 DI-1 ①~③에 옮겨 적어요.
  • 막히면 맨 아래 AI 질문 만들고 복사를 눌러 평소 쓰는 AI에 붙여 넣어요.

정리한 내용은 지금 이 기기에만 남아요. 협의가 끝나면 바로 저장해서 올려 주세요. 맨 위에서 팀 번호를 먼저 골라야 해요.
